# Scientific Data Visualization Project

Course project for **Scientific Visualization**, for MSc Computer Science
(LM-18), Università degli Studi di Milano.

## What this repository contains

Python scripts that pull open data (gnomAD v4 allele counts and CPIC pharmacogene
annotation), analyse East Asian versus South Asian allele-frequency differences in
pharmacogenes, and produce the project's figures.

The genetic data are gnomAD reference groups, selected to reflect different ethnic
groups present in Singapore.

## Dataset

No dataset is redistributed here. Everything is fetched by script from three open sources,
none of which needs a login or an access committee. A clean checkout can regenerate the
whole dataset by running the pipeline below. Access date for every number quoted in this
repository: **2026-11-10**.

| Source | Endpoint | Used for |
| --- | --- | --- |
| gnomAD v4 (GRCh38) | `https://gnomad.broadinstitute.org/api` (GraphQL) | Allele counts per population, exome and genome callsets summed |
| CPIC | `https://api.cpicpgx.org/v1` (REST) | Gene-drug pairs and evidence levels, allele definitions, allele function labels |
| HGNC | protein-coding gene table, direct download | Gene symbols from which random comparison genes are drawn |

The pulls land in `data/raw/` and the derived tables in `data/processed/`. Neither is
committed.

| File | Contents |
| --- | --- |
| `data/raw/genes.csv` | 119 CPIC genes with an active gene-drug pair, flagged level A or other |
| `data/raw/allpop_pharmacogenes.csv` | Every gnomAD variant at AF >= 0.1% in those genes, with `ac` and `an` for eight groups |
| `data/raw/allpop_background.csv` | The same for 120 randomly drawn protein-coding genes |
| `data/processed/gene_divergence.csv` | Per gene: pooled Hudson FST, the value with its most divergent variant removed, variant count, CPIC level A flag |
| `data/processed/variant_tests.csv` | Per variant: frequencies in both groups, the difference, and BH-adjusted p-values |
| `data/processed/carrier_rates.csv` | Per gene-drug pair and population: carrier frequency for the curated core alleles |
| `data/processed/gene_levels.csv`, `background_gene_fst.csv` | FST by CPIC evidence level, and the random-gene baseline |
| `data/processed/pca_*.csv` | PCA scores, variance explained, and the subsampling control |

Groups used: East Asian (`eas`) and South Asian (`sas`) for the divergence analysis,
European (`nfe`) as a reference for carrier rates, and all eight groups (`afr`, `amr`,
`asj`, `eas`, `fin`, `mid`, `nfe`, `sas`) for the PCA. There is no Malay group in gnomAD,
which is the main limitation of using open data for a Singapore-motivated question.

## Project structure

```
scripts/        the analysis pipeline, numbered in run order
  style.py      shared palette and matplotlib settings; SDV_DECK=1 switches to slide sizes
notebooks/
  analysis_walkthrough.ipynb   the analysis explained figure by figure, outputs included
figures/        f1 to f7, PNG at 220 dpi (committed) and SVG (not committed)
data/           raw pulls and derived tables (not committed; regenerated by the scripts)
docs/           research question, data sources, analysis workflow, design rationale
presentation/   the slide deck, its build script, and the speaker script
```

Start with `notebooks/analysis_walkthrough.ipynb` for the analysis, or
`docs/00-project-handbook.md` for every decision taken and why.

## Running the analysis

    python3 scripts/01_pull_cpic_genes.py           # CPIC genes and levels
    python3 scripts/02_pull_gnomad.py background    # random comparison genes (about 30 min)
    python3 scripts/02_pull_gnomad.py pharmacogenes # CPIC genes (about 35 min)
    python3 scripts/03_analyse.py                   # FST, permutation test, figures F1-F3
    python3 scripts/04_carrier_rates.py             # carrier rates for core alleles
    python3 scripts/05_carrier_figure.py            # figure F4
    python3 scripts/06_baseline_and_levels.py       # random-gene baseline, FST by CPIC level, F5
    python3 scripts/07_population_pca.py            # population PCA and control, F6
    python3 scripts/08_variant_tests.py             # per-variant test, BH correction, F7

Steps 1 and 2 need network access and take about an hour. Everything after that runs
offline from the cached pulls in under a minute. All seeds are fixed at 0.

Set `SDV_DECK=1` on the figure scripts to write slide-sized 300 dpi versions into
`presentation/assets/figures/`, then build the deck with
`python3 presentation/build_deck.py`.

## Tools used

Python 3.9 or later, with pandas, numpy, scipy, matplotlib and requests. Developed against
Python 3.9.7, pandas 1.3.4, numpy 1.26.4, scipy 1.13.1 and matplotlib 3.4.3.

`python-pptx` builds the slide deck. Jupyter is needed only to open the walkthrough
notebook, which is saved with its outputs and so can be read without running it.

## Summary of results and limitations

Four questions, two of which were framed so that a null answer is informative.

**Q1. Which pharmacogenes differ most between East and South Asian reference groups?**
VKORC1, at a pooled Hudson FST of 0.40 against a pharmacogene median of 0.047. The second
highest is GSTM1 at 0.26. Removing a single variant from VKORC1 drops it to 0.030, which is
below the median of an ordinary gene, and no other gene in the top 15 moves appreciably. The
gene is unremarkable; one site in it is not, and that site is the promoter variant behind the
CPIC warfarin dosing guideline. Figures F1 and F7.

**Q2. Do genes with an actionable CPIC guideline (level A) diverge more than other
pharmacogenes?** No evidence of a difference. Median FST 0.052 against 0.047, one-sided
permutation p = 0.20 over 10,000 permutations, and no trend across evidence levels A to D
(p = 0.64). Figures F3 and F5.

**Q3. For the variants that already carry a dosing guideline, how many people carry one?**
This is where a population difference becomes a clinical one. 99% of East Asians carry a
VKORC1 warfarin-sensitivity variant against 32% of South Asians, a gap of 66 percentage
points. CYP2C9 and UGT1A1 run the other way, 23 and 18 points higher in South Asians.
Figure F4.

**Q4. Do pharmacogenes as a class diverge more than ordinary genes?** No evidence of a
difference. Median FST 0.047 against 0.050 for 81 random genes, one-sided permutation
p = 0.53. A PCA of the eight gnomAD groups built from pharmacogenes alone reproduces the
layout built from random genes with a distance correlation of 0.99. Figure F6.

A methodological result worth stating separately: 3,203 of the 3,313 common variants tested
(97%) have a Benjamini-Hochberg adjusted p-value below 0.05, and every variant differing by
at least two percentage points clears that threshold. At gnomAD's sample sizes the p-value
measures the size of the cohort, not the size of the difference, so every ranking in this
project uses effect size instead. Figure F7.

### Limitations

| Limitation | What it limits |
| --- | --- |
| Reference groups, not residents | Results describe gnomAD reference populations, not any country's population |
| No Malay group | One of the three Singaporean communities cannot be assessed with open data |
| Groups compared by label | Nothing here supports an inference about an individual |
| Frequency is not drug response | A guideline may apply; a change in outcome is not implied |
| Only 81 random genes passed filters | A small class-level difference could be missed |
| Some genes unreadable from SNV frequencies | CYP2D6, HLA genes, TPMT and CYP2B6 need haplotypes or copy number; DPYD is under-counted at 2 of 4 curated variants |
| Alleles counted, not people | The per-variant test treats a person's two chromosomes as independent, which inflates significance |
| Exome and genome callsets summed | The two are not de-duplicated, so a few individuals may be counted twice |

`docs/02-research-question.md` states each question in full and `docs/04-analysis-workflow.md`
documents the pipeline stage by stage, including the limitations of the FST implementation.
