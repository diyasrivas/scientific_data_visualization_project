# Scientific Data Visualization Project

Course project for **Scientific Visualization** (6 ECTS, INFO-01/A), MSc Computer Science
(LM-18), Università degli Studi di Milano.

## What this repository contains

Python scripts that pull open data (gnomAD v4 allele counts and CPIC pharmacogene
annotation), analyse East Asian versus South Asian allele-frequency differences in
pharmacogenes, and produce the project's figures. `data/` and `figures/` are generated by
the scripts and are not committed.

The genetic data are gnomAD reference groups, not Singapore residents, and gnomAD has no
Malay group.

## Running the analysis

    python3 scripts/01_pull_cpic_genes.py           # CPIC genes and levels
    python3 scripts/02_pull_gnomad.py background    # random comparison genes (about 30 min)
    python3 scripts/02_pull_gnomad.py pharmacogenes # CPIC genes (about 35 min)
    python3 scripts/03_analyse.py                   # FST, permutation test, figures F1-F3
    python3 scripts/04_carrier_rates.py             # carrier rates for core alleles
    python3 scripts/05_carrier_figure.py            # figure F4
    python3 scripts/06_baseline_and_levels.py       # random-gene baseline, FST by CPIC level, F5
    python3 scripts/07_population_pca.py            # population PCA and control, F6

Requires Python 3 with pandas, numpy, scipy, matplotlib and requests. The gnomAD API
rate-limits, so the pulls are slow.

`scripts/style.py` holds the shared colour palette used by every figure.
